安全与合规

隔离、审计、密钥与出网边界落在架构与交付基线上，逐条对应交付包《部署指南》的安全基线章节。

架构级数据隔离

每员工独立实例（StatefulSet）与专属存储卷（PVC）；实例流量锁定在集群边界内，实例 Pod 不挂载集群管理凭据。

审计留痕

管理面操作全量审计（控制台可查），运行时网关对写操作逐条审计上报；留存与归档策略按企业合规要求配置。

OIDC / SSO

标准 OIDC 对接企业自有 IdP，角色自动映射；可强制 SSO 登录，员工不另设平台密码。

密钥管理

凭据全部以 Kubernetes Secret 注入；签名密钥与加密根纳入【密钥】清单，按企业密管流程离线备份，不在代码与工单中落值。

信创适配

平台组件与实例镜像提供 Linux ARM64（鲲鹏 / 飞腾）构建，桌面端支持麒麟 / 统信（arm64 deb / rpm）；支持人大金仓 KingbaseES（PG 兼容模式，交付前按目标版本完成验收）。

私有化出网约束

平台组件除授权激活与更新检查两条可控外联外，无遥测、无数据上报；实例模型推理只发往企业自行配置的模型渠道；支持纯内网形态（自建授权服务 + 私有更新通道 + 镜像全量入仓）。

数据留在企业自己的集群：隔离、审计与密钥管理是交付基线，不是宣传语

等保、ISO 27001 等第三方认证：尚未取得，本页不作"已认证"表述；平台安全设计支持企业按等保等要求开展自有测评与申报，交付基线明细见交付包《部署指南》安全基线章节。法务文档（隐私政策 / 服务条款 / EULA / DPA）草案整理中，正式版发布前如需获取，请致函商务邮箱。
