WorkPaw 是什么

一套平台，服务三类角色，共享同一套品牌与信任契约。

员工
日常使用 AI 助手完成工作——桌面客户端与 Web 应用，SSO 登录后即可对话、管理文件、审批流程。
配置者
配置 Agent、技能、模型与渠道集成。低频但关键：配好一次，全员受益。
管理员
治理全部用户实例的生命周期、资源用量、审计日志、全局策略与 OIDC 连接。

为企业而生

  • 私有化部署——部署在企业自己的 Kubernetes 集群，Helm 一键安装，数据不出内网。
  • 多用户隔离——每位员工独立容器实例，数据隔离在各自的持久卷中。
  • 企业身份集成——对接企业 SSO / OIDC，员工用现有账号直接登录。
  • 全程可审计——全平台实例状态与操作轨迹，管理员一览无余。
  • 全平台桌面端——macOS（Apple Silicon / Intel）、Windows、Linux x64 与 ARM64（鲲鹏 / 飞腾）。
